# A book search app based on the OpenLibrary API

## Tech Stack

- Vite
- React
- react-hook-form
- TypeScript
- Tailwind css

## Features

- This project uses the [OpenLibrary API](https://openlibrary.org/) to support you in finding out more about your favourite books.
- You can search by title, search by genre, search by publish year and  search by author. 
- Provide an advanced search mode with combination of the above criteria and an additionnal critierium: the language
- Favourite books stored in the web browser
